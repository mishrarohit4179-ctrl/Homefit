01
Information We Collect

HomeFit ek static fitness website hai jo minimum data collect karta hai. Humara goal hai aapko best experience dena aapki privacy protect karte hue.

✅ Hum koi bhi personally identifiable information (PII) — jaise naam, email, phone number, address — collect, store ya process nahi karte.

Automatically collect hone wala basic information:

  • Browser type aur version (anonymous analytics ke liye)
  • Device type — mobile ya desktop (UI optimization ke liye)
  • Pages visited aur time spent (anonymous, aggregated)
  • Referrer URL — aap kahan se aaye (traffic source samajhne ke liye)

Yeh sab information aggregate form mein hoti hai — aapko personally identify karne ke liye use nahi hoti.

02
Local Storage Data

HomeFit ke fitness tools — 30-Day Challenges, Progress Tracker, HIIT Timer — aapka data save karte hain. Yeh data exclusively aapke device ke browser localStorage mein store hota hai.

  • Challenge progress (completed days, exercise logs)
  • Progress Tracker entries (weight, strength data)
  • Photo reminder status
  • Calculator ke last used values

🔒 Yeh data kabhi bhi humhare servers par nahi jaata. Sirf aapka browser is data ko rakhta hai. Aap kabhi bhi browser settings se yeh data delete kar sakte hain.

Agar aap browser data clear karte hain ya incognito mode use karte hain, toh yeh saved data automatically delete ho jaata hai.

03
How We Use Information

Jo limited anonymous information hum collect karte hain, uska use sirf in purposes ke liye hota hai:

  • Website performance improve karna
  • Kaunse features popular hain yeh samajhna
  • Technical bugs aur errors fix karna
  • User experience better banana

Hum yeh information kisi bhi third party ko sell, rent ya trade nahi karte marketing purposes ke liye. Aapka data hum kabhi bhi monetize nahi karte.

04
Cookies

HomeFit limited cookies use karta hai. Hum tracking ya advertising cookies use nahi karte.

  • Essential Cookies: Website ke basic functions ke liye zaroori — session management
  • Preference Cookies: Aapki settings save karne ke liye jaise theme preference

Aap apne browser settings se cookies disable kar sakte hain, lekin isse website ke kuch features kaam nahi karenge properly.

📢 Hum Google Analytics, Facebook Pixel ya koi advertising network use nahi karte is website par. Aap ad-free experience enjoy karte hain.

05
Third Party Services

Website proper function karne ke liye kuch third-party services use karti hai:

  • Google Fonts: Typography ke liye — fonts load karte time Google ke servers se request jaati hai
  • Unsplash: Exercise aur fitness images ke liye — CDN se serve hoti hain
  • Netlify: Website hosting provider — unki privacy policy apply hoti hai

Yeh services apni own privacy policies follow karti hain. Hum recommend karte hain ki aap unki policies bhi review karein agar concerned hain.

06
Children's Privacy

HomeFit 13 saal se kam umra ke bachon ke liye designed nahi hai. Hum knowingly 13 saal se kam umra ke bachon ka koi personal data collect nahi karte.

Agar aap parent ya guardian hain aur aapko lagta hai ki aapke child ne humein koi personal information provide ki hai, toh humse contact karein. Hum us information ko immediately delete karenge.

07
Your Rights

Aapke paas apne data ke baare mein yeh rights hain:

  • Access: Jaanne ka haq ki hum aapka kaun sa data rakhte hain (hum rakhte hi nahi practically)
  • Delete: Apna localStorage data browser settings se khud delete kar sakte hain
  • Opt-out: Browser settings se cookies disable kar sakte hain
  • Portability: Aapka data aapke device par hai — aap use control karte hain

💡 Apna localStorage data delete karne ke liye: Browser Settings → Privacy → Clear Browsing Data → Local Storage select karo → Clear karo. Ya directly browser DevTools mein jaake Application → Local Storage → homefit data delete kar sakte hain.

08
Data Security

Kyunki hum koi personal data apne servers par store nahi karte, data breach ka risk practically zero hai humari side se. Aapka fitness data sirf aapke device par rehta hai.

Website HTTPS (SSL/TLS encryption) use karti hai — iska matlab aapka browser aur humara server ke beech communication secure hai.

Fir bhi, koi bhi internet transmission 100% secure nahi hoti. Hum commercially reasonable measures use karte hain website ko secure rakhne ke liye.

09
Policy Changes

Hum is Privacy Policy ko update kar sakte hain time to time — website improvements ya legal requirements ki wajah se. Koi bhi significant change hone par is page par "Last Updated" date change hogi.

Aap regularly is page ko visit kar sakte hain latest policy check karne ke liye. Website ka continued use updated policy ki acceptance maana jaayega.
